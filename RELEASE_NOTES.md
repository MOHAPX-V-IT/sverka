# 0.1.0-rc.1

Snapshot, diff, full verify, SHA-256, bounded workers, move detection, JSON/human output, prefix exclusions, explicit symlink policy, durable JSONL checkpoint/resume и atomic snapshot replacement. Snapshot schema 1. Resume доверяет size/mtime; после него нужен verify. Не является live filesystem snapshot или системой резервного копирования содержимого.
